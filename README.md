# Homepage

Homepage project developed as part of the Advanced HTML and CSS course from [The Odin Project](https://www.theodinproject.com/paths/full-stack-javascript/courses/advanced-html-and-css), focused on layout, typography, and responsive design.

## Project Objective

The main goals were to practice:
- Building a multi-section layout with a clear visual hierarchy
- Using custom fonts and icon assets in a static page
- Creating a responsive layout with flexible cards and breakpoints
- Practice with Media Queries
- Styling backgrounds with pseudo-elements and CSS effects

## What Is It?

A static portfolio-style homepage with **About**, **My Work**, and **Contact sections**. It includes a skewed hero background, project cards with images, and a contact area with social icons.

## How To Use

1. Go to the project folder:
   `cd Advanced HTML and CSS/top-homepage`
2. Open `index.html` in your browser.

## Features

- Multi-section layout with **About**, **Work**, and **Contact blocks**
- Skewed background effect using a pseudo-element
- Project cards with images and icon buttons
- Custom fonts loaded via `@font-face`
- Responsive layout with media queries

## File Structure

- `index.html`: page markup
- `style.css`: layout, typography, and responsive styles
- `imgs/`: project and profile images
- `icons/`: social and action icons
- `fonts/`: local font files

## Technologies Used

- HTML
- CSS
